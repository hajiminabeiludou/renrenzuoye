# v1.2 控制台业务流程审核记录

审核人：丁文韬

被审核版本：`v1.2-original`

建议修复版本：`v1.2-reviewed`

## 审核范围

本次审核重点检查 `main.cpp` 和 `app.cpp` 中新增的控制台业务流程，包括登录注册、发布失物招领、提交认领、管理员审核、统计和操作日志。

## 审核意见

1. 控制台提示文字仍然大量使用英文，例如 `Login`、`Register student`、`Choose`、`Invalid input` 等。作业要求系统界面更贴近中文使用场景，建议统一改为中文提示。

2. 业务代码中仍存在较多魔法数字，例如用户角色 `0/1`、物品状态 `0/1/2`、认领状态 `0/1/2`。v1.0 已经增加了枚举常量，v1.2 应该继续使用 `ROLE_STUDENT`、`ROLE_ADMIN`、`ITEM_OPEN`、`CLAIM_PENDING` 等常量，减少误用风险。

3. 多处调用 `saveAll` 后没有检查返回值，例如注册、发布、提交认领、审核和退出保存。如果保存失败，界面仍提示操作成功，可能造成数据丢失。

4. 注册功能缺少空值校验，用户名、密码、真实姓名和手机号都可以为空。建议至少校验用户名和密码不能为空，避免产生无法管理的无效账号。

5. 发布物品时分类编号只限制在 `1-9999`，没有确认编号是否真实存在。用户输入不存在的分类编号后，后续展示会显示未知分类，影响数据质量。

6. 管理员审核功能会展示待审核申请，但没有同步展示对应物品标题和申请人联系方式，审核信息不够完整。当前版本可以运行，但后续建议补充更多上下文。

## 审核结论

v1.2 原始版已经把系统从“数据存储模块”推进到“可操作的控制台业务系统”，主流程完整，能够支撑学生发布和管理员审核的基本演示。

但当前版本在中文界面、枚举常量使用、保存失败处理和输入校验方面仍需修改。建议按以上意见提交 `v1.2-reviewed-console` 修改版。
